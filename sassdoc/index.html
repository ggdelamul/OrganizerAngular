    dimension

    @mixin dimension($height, $width, $min-width, $max-width) { ... }

    Description

    Applique des dimensions personnalisées à un élément, si elles sont définies. Les valeurs nulles sont ignorées.

    Parameters

    parameter Nameparameter Descriptionparameter Typeparameter Default value
    $height

    La hauteur de l’élément (ex : 100px, auto). Optionnel.

    		Length or Null— none
    $width

    La largeur de l’élément. Optionnel.

    		Length or Null— none
    $min-width

    La largeur minimale. Optionnel.

    		Length or Null— none
    $max-width

    La largeur maximale. Optionnel.

    		Length or Null— none

    Example

    Utilisation classique

    .card {
  @include dimension(100px, 200px, 150px, 300px);
}

    Used by

    • [mixin] button
    • [mixin] input-text
    • [mixin] input-checkbox

    flex

    @mixin flex($direction, $gap, $align, $justify) { ... }

    Description

    Crée un conteneur flex avec direction, alignement, espacement et justification personnalisables.

    Parameters

    parameter Nameparameter Descriptionparameter Typeparameter Default value
    $direction

    La direction des éléments (row, column, etc.).

    		String— none
    $gap

    L'espacement entre les éléments (par ex. 1rem, 10px). Optionnel.

    		Length or Null— none
    $align

    L'alignement vertical (center, flex-start, etc.). Optionnel.

    		String or Null— none
    $justify

    L'alignement horizontal (center, space-between, etc.). Optionnel.

    		String or Null— none

    Example

    Utilisation de base

    .container {
  @include flex(row, 1rem, center, space-between);
}

    Used by

    • [mixin] card

    grid

    @mixin grid($columns, $rows, $gap, $fr) { ... }

    Description

    Crée un conteneur grid avec un nombre de colonnes et lignes personnalisable.

    Parameters

    parameter Nameparameter Descriptionparameter Typeparameter Default value
    $columns

    Nombre de colonnes du grid.

    		Number— none
    $rows

    Nombre de lignes. Optionnel.

    		Number or Null— none
    $gap

    Espacement entre les lignes et colonnes. Par défaut : 0.

    		Length— none
    $fr

    Unité de fraction utilisée dans repeat(). Par défaut : 1fr.

    		String— none

    Example

    Grid simple

    .container {
  @include grid(3, 2, 1rem);
}

    border

    @mixin border($color, $width, $radius, $isbordervisible) { ... }

    Description

    Applique une bordure personnalisée si visible, avec arrondies facultatif.

    Parameters

    parameter Nameparameter Descriptionparameter Typeparameter Default value
    $color

    Couleur de la bordure. Optionnel.

    		Color or Null— none
    $width

    Épaisseur de la bordure. Optionnel.

    		Length or Null— none
    $radius

    Arrondies de bordure (coins arrondis). Optionnel.

    		Length or Null— none
    $isbordervisible

    Si true, applique la bordure ; sinon, border: none. Par défaut : false.

    		Boolean— none

    Example

    Bordure visible

}

    • [mixin] input-checkbox

    button

    @mixin button($height, $width, $max-width, $background-color, $text-color, $shadow) { ... }

    Description

    Génère un bouton avec dimensions, couleurs, et option d’ombre portée. Utilise les mixins dimension() et box-shadow().

    Parameters

    parameter Nameparameter Descriptionparameter Typeparameter Default value
    $height

    Hauteur du bouton (ex: clamp(35px, 5vw, 45px)).

    		Length— none
    $width

    Largeur du bouton (ex: 100%).

    		Length— none
    $max-width

    Largeur maximale du bouton. Optionnel.

    		Length or Null— none
    $background-color

    Couleur de fond du bouton.

    		Color— none
    $text-color

    Couleur du texte du bouton.

    		Color— none
    $shadow

    Applique une ombre si true. Par défaut : false.

    		Boolean— none

    Example

    Bouton violet sur fond clair

    .my-button {
  @include button(45px, 100%, 160px, $primary, $white, true);
}

    Requires

    • [mixin] dimension
    • [mixin] box-shadow
    • [mixin] box-shadow

    input-text

    @mixin input-text($width, $background-color, $shadow: false) { ... }

    Description

    Applique les styles d'un input de type texte.

    • Couleur de fond personnalisable
    • Possibilité d'ajouter une ombre via un autre mixin
    • Padding horizontal par défaut (24px)

    Parameters

    parameter Nameparameter Descriptionparameter Typeparameter Default value
    $width

    Largeur de l’input (ex. 100%, 200px, etc.)

    		Length— none
    $background-color

    Couleur de fond de l’input

    		Color— none
    $shadow

    Active ou non l’ombre portée (non utilisé ici mais prévu)

    		Booleanfalse

    Requires

    • [mixin] dimension
    • [mixin] border
    • [variable] black
